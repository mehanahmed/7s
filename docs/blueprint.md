# **App Name**: TrackFlow

## Core Features:

- Role-Based Access: Admin and user roles with distinct access levels: Admin, CRM, and DR. Admins can manage users and their roles.
- Tracking Link Generation: CRM users generate unique tracking links using customer information (name, company name, address). Each link includes a unique, unguessable order ID. Link defaults to non-public until designer sets it as public. Designer can assign status to link.
- Public Tracking View: Public tracking link view displays relevant information (customer name, role) and allows unlimited commenting from clients, logistics, or other stakeholders.
- Order History & Search: Order history with search functionality. The system maintains an immutable log that is searchable by order ID or CRM name, and includes who changed the status and when it was changed.

## Style Guidelines:

- Primary color: Strong blue (#468B97) for trust and reliability. Blue is a common choice for SaaS dashboards.
- Background color: Light gray (#E0E5E7), providing a neutral backdrop that won't distract from the data.
- Accent color: A muted purple (#8675A9). It adds a touch of uniqueness without being too overpowering.
- Clean and professional typography to ensure readability and a modern feel.
- Consistent use of simple, outline-style icons throughout the application.
- Clear and intuitive layout, with a focus on data presentation and ease of navigation.
