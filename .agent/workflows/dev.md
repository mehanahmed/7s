---
description: How to run the application locally for development.
---

1. Ensure environment variables are set in `.env`.
// turbo
2. Install dependencies:
   ```bash
   npm install
   ```

// turbo
3. Start the Next.js development server (available on port 9002):
   ```bash
   npm run dev
   ```

// turbo
4. Start Genkit AI for local development:
   ```bash
   npm run genkit:dev
   ```

// turbo
5. In a separate terminal, view the Genkit UI:
   ```bash
   npx genkit ui
   ```
